# 學員蒙恩見證稿編輯器

這是一個可在瀏覽器使用的學員蒙恩見證稿編輯器，做法參考既有的主日申言稿編輯器。

## 功能

- 填寫組別範圍、姓名、週次、日期、主題
- 填寫「在訓練生活中」與「在當地召會生活中」兩段見證內容
- 即時預覽學員蒙恩見證稿版面
- 產生並下載可編輯的 A4 Word 文件
- 以固定 A4 版面產生並下載 PDF
- 手機版可使用「分享 Word」叫出系統分享面板

## 使用方式

直接開啟 `index.html`，或部署到 GitHub Pages 後使用公開網址。
